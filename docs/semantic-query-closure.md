# 通用语义查询主责复验与收口

2026-09-14。验收依据为 Q0–Q4 交付、实际代码和新增反例；不是直接采纳交付报告中的“全部通过”。

## 结论

已修复本轮发现的静默漏算、意图约束绕过、业务字段写死、重复统计路径和选择恢复问题。当前可作为**有明确能力边界的只读企业分析系统**使用；不能据此宣称任意自然语言问题都能正确解释，也没有把原始业务数据、全部法规/审计定义或生产部署验收标成已通过。

新增企业在已支持的来源协议和算子范围内，只需配置 Domain Pack、Integration Binding 和环境连接。业务定义决定指标、单位、统计粒度、年度属性、别名、对象身份及 Rule；核心不含财税/仓库指标、字段名或企业编号分支。新增协议或尚未支持的算子仍需要通用能力实现，不能承诺“任何来源、任何分析均不改代码”。

## 修复内容

| 复验发现 | 最终处理 |
|---|---|
| runtime 直接导入 PostgreSQL、SQLGlot 并解析物理字段 | 物理规划/执行集中在 `adapters/analysis.py`；runtime 通过 prepare/execute/候选能力调度，公共参数仍为语义类型 |
| 多指标只执行第一个；分组说明只展示第一行 | 同表多指标完整执行并逐项说明；每个指标保留范围统计，分组逐行展示；任一指标缺失时不交付部分数值冒充完整请求 |
| 年度字段写死 taxYear/stockYear/year | 仅使用 Metric.population.yearProperty；新增 fiscalCycle 配置反例，不修改核心即可执行 |
| 模型可改写原问题、跳过歧义或擅自 exclude | 始终以原始用户文本校验明确约束；歧义由服务器候选决定；模型不能提交 decisions，也不能自己声明用户授权 |
| “收入多少”自动假定 SUM | 指标、年度、聚合方式逐项选择；未明确聚合不默认合计 |
| 同名主体、多种比较口径、矛盾 EQ 条件 | 返回真实对象/口径/条件选择；没有数据、来源故障与矛盾条件分开处理 |
| 点查/Rule 有证据即可附任意确定性散文 | 确定性回答由来源观测及 Rule truth 生成，模型文字不能把 UNKNOWN 改为通过；不支持说明仍单独标识 |
| 分组 AVG 按 SUM 排名、并列顺序不稳定 | 均值排序使用数据库数值除法；按分组键稳定处理并列，不把前 N 个当作唯一胜出者 |
| NULL 主体误报不存在；主体复合筛选错误排除同行 | 存在性按记录数判断，NULL 保留未知；同行排除已解析身份，不逐项对筛选字段取反 |
| 总体、比较和明细多次读取可能变化 | 一次同源分析共用只读 REPEATABLE READ 事务；限制属于单数据源快照 |
| 计划摘要仅覆盖 SQL 文本 | 绑定完整语义请求、值、租户和发布摘要；执行重新规划校验，拒绝变更值/版本复用 |
| 保存选择后再保存回答，失败会丢失待办 | 回答、清除 pending 和保存 query_state 同一事务；失败保留原选择可重试 |
| 物理 mappingFields 绕过 lineage 可见性 | 模型工具返回及普通分析身份移除物理表列；有建模权限的页面用表格展示映射 |
| 原统计工具、意图校验、说明与 hooks 多路并存 | Chat 仅保留 prepare_semantic_query；旧 HTTP analyze 仅翻译。旧 Chat population 执行、TurnIntent.check 和旧说明函数删除；hooks 根据服务器 waiting/answerReady 统一结束 |

## 当前能力边界

- 同源、同事实表：类型化 AND/OR/NOT 过滤、SUM/AVG/MIN/MAX/COUNT、业务字段分组、整数年度及已声明日期字段时间分组、排序与 Top N、多指标读取、三类主体比较。
- 统计集合不再限制 50 行；50 是每个指标的证据明细上限。单请求最多 8 个指标、8 个分组键、1000 个结果分组；达到结果预算明确要求缩小范围，不能截断后判断不存在。
- 年度范围可用 IN/BETWEEN；同一企业不同年度不会被误当重复统计单位。重复企业年度仍拒绝，不能拿 DISTINCT 金额掩盖。
- 集合分析的跨事实表 Link JOIN、跨库 SQL、窗口函数、任意用户 SQL、复合身份、多指标联合排序/比较仍未完成。返回明确能力错误；**Q0 中这些更广目标不因本轮同表通过而关闭**。已有点查/Rule 的声明式 Link 能力保持独立用途。
- 只有明确定义的 Rule 才能得出对应判断；“没有审计定义”不能回答“已通过审计”。系统不从本体图形自动推导未定义的业务规则。
- 意图校验覆盖明确年份、指标词汇、统计操作、比较、缺失授权及服务器选择；不声称对任意复杂自然语言都存在完备的形式化证明。模型仍可能多问一次，或对尚不支持的需求说明无法完成。
