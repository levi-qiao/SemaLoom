## 企业差异放在哪里

- `domain`：业务对象、属性、指标、别名、统计单位与年度、公式和 Rule。相同“收入”可以有多个明确候选，不在系统 prompt 写某家企业的解释。
- `integration`：数据表/字段、来源协议、关联与映射；连接认证走环境绑定。
- `core/compiler/runtime`：类型、粒度、集合完整性、Decimal、缺失语义、规则执行和证据；不导入企业定义。
- `app/chat` 与 `harness`：通用工具 schema、明确意图检查、模型生命周期与展示；不保存企业公式。

在已有协议与受支持分析算子内，更换企业主要配置本体及来源绑定。新协议仍需 adapter，新统计能力仍需通用算子；不能宣称只画实体图就能准确理解任何业务系统。

## 实测证据

所有新增业务值均为发明的隔离数据，未改共享样本库、:8000 发布指针或真实数据。

- Python 全量：215 PASS / 1 既有 JWT FAIL / 1 原生 MCP SKIP，结果见 `.agents/audit-fixes/pytest-final.log`；生产 JWT 的既有失败与原生 MCP 未运行单列。独立 SQL/Decimal gold 用例保留，不用被测引擎给自己生成数值期望。
- pi 原生 hooks：4 项通过；包括 analyze_population 直接交付服务器说明、无需第二轮模型计算。
- 浏览器最终 22 项通过（含配置保留检查），涵盖 390/1280px、就地新建、证据表、保存/发布/重载。真实浏览器六节点八条关系：标签互遮 0，工具栏与画布分离。隔离财务模型通过页面修改别名与指标名、保存重载后，companyId/taxYear/范围说明完整保留。
- 真实 qwen3.7-plus：首轮 10 道审计原题，6 PASS / 4 FAIL。根据实际失败确认 provider 将嵌套对象字符串化后修复 schema，定向复验 4 道全部 PASS。合计 14 次 Chat 请求，不隐藏首轮失败，不把分轮复验称为一次 10/10。
- 三项比较复验各 2 次工具调用：140 / 500 = 28%；(140 − 125) / 125 = 12%；严格胜出 2 / 3 = 66.66666666666666666666666667%。金额/数量/比例文字由引擎值生成。原“收入”和“占优”题澄清；缺失 reject 不出数，明确 exclude 为 280 / 3。
- 第一轮非存在企业题受缺失 Company 表影响；复验补齐隔离 Company 表，成功空搜索后澄清，不把 provider 故障当不存在。

报告分别说明确定性数值、模型意图和源数据可靠性。此处的小批真实模型测试不构成全自然语言准确率。

## 仍然明确受限

当前为同源同事实表集合分析；证据明细每指标最多 50 行分页，不是总体对象数上限。不支持无界聚合、任意跨表 group-by、跨年度复合粒度或全局跨源快照。明确中英意图检查是保守约束，不是完整语言解析器。生产 JWT、原生 MCP transport、真实企业数据复核与生产负载 gate 未因此关闭。60/200 节点密集图和浏览器 200% 缩放本轮未验收。

## 可直接派给测试 Agent 的提示词

所有 Agent 使用自己的隔离数据库/端口/临时目录，读 AGENTS.md 与本文；默认只验证，发现问题写最小复现，禁止修改共享样本、发布指针或打印 provider 密钥。

**A：通用性与配置。** Goal：在不修改 core/runtime/harness 的前提下，用合成“设施产出”或其他非财税领域定义至少两种有歧义的业务指标，绑定隔离 PostgreSQL。验证别名澄清、单年度统计、业务规则和来源表格。通过页面修改指标名称、别名、统计单位/年度后保存重载，确认配置不丢失；对非法年度属性/重复统计单位验证编译或执行拒绝。报告每步证据，不把配置成功当分析正确。

**B：AI 意图与反例。** Goal：先使用离线 pi faux provider 覆盖嵌套对象、错误字符串、缺失政策、比较分母、多个年份/指标和提示注入；需要真实模型时使用已有授权 provider，最多 12 个问题、失败不自动重试。挑未出现在审计中的自然表述，独立检查对象、年度、操作、分母与正文；正确卡加错误正文也判失败。不得使用 analyze_population 本身生成数值期望，保留失败调用码与最小复现。

**C：页面和全链路。** Goal：在隔离服务验收用户提问 → pi → Python → 数据库 → 证据保存 → 页面表格 → 刷新。模拟保存失败/来源错误/缺失/切版本，不能显示成功或错误数值。测试 390/1280/1440px、真实 200% 浏览器缩放、60/200 节点与长中文关系；新建、连接、取消、整理、缩放后标签可读。列通过/失败/未执行，截图只保存在项目私有目录。
