# 行为验收矩阵

这是后续实现的验收目标，不是已通过测试报告。每个执行任务将对应 ID 映射到可重复测试/实验，交接中提供命令、结果和 fixture。关键不变量必须全部满足；测试范围可扩展，不能为获得绿色结果降低要求。

所有默认数据是合成数据。真实政策正确性和生产容量只能在具备授权与明确条件的环境中验证。

## 模型与 Compiler

| ID | 场景 | 期望证据 |
| --- | --- | --- |
| A01 | 合法领域包编译、字段重排后重新编译 | 输出规范化 bundle；语义相同输入有相同 digest |
| A02 | 重复 semantic ID、悬空引用、包依赖缺失/环/命名空间冲突、未声明跨包引用、错误维度类型、未知核心字段 | 编译失败，定位到定义与字段；无隐式类型纠正 |
| A03 | Rule/派生指标依赖环、缺少 Link 身份绑定 | 拒绝无效依赖；合法 Object 关系环不被误当 Rule 环 |
| A04 | grain、单位、聚合维度不完整；同口径多个模糊 Mapping | 定义错误可在编译期拒绝，动态歧义明确报告 |
| A05 | 数据源离线、目标 schema 改变、DSL 自填 approvedBy | 离线 compile 与联机验证分开；伪造字段无法变成可信发布 |

## PoC gate

T07 完成时 A01–A46 与 A50–A63 全部通过，才可称为本计划范围内的 PoC 完成。A49 属于 T08A 开源准备，A47–A48 属于 T08B 真实 pilot；两组独立记录，未满足项单列，公开发布准备不能替代生产验证。某种能力若本来就不在首版支持 profile，验证的是它被明确拒绝，而不是虚构实现。

## Studio gate

T09C 完成且 A64–A69 全部通过才表示工作台完成。A64/A69 的合成界面通过不关闭真实保存、API 来源或权限验收。T08A 产品发行准备同时依赖 backend PoC 与 Studio gate。
