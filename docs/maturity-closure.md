# 通用业务建模平台收口清单（历史广义范围）

> **优先级**：当前交付与验收以 [PLAN §8](PLAN.md)、[主责收口](semantic-query-closure.md)、[AI 分析](ai-analysis.md) 为准。本页保留为后续成熟度目录，不覆盖上述优先级。

**范围更新**：用户已明确优先“准确的只读业务分析能跑通”，不建设过度设计的权限/Action/MCP 平台。本页六组工作保留为后续成熟度目录，不再全部作为当前任务前置条件。typed Rule、身份存在性、实例搜索、完整结构化身份（点查/Link/Action）、工具 Schema、粒度和期间检查已实现；跨源集合分析的复合 Link、生产身份、Action 恢复仍未完成。


本轮核对 G1–G5 交接、当前实现及 `docs/acceptance.md`。目标是声明范围内可交付、可维护的业务建模平台：新增同协议业务主要增加领域定义与接入绑定，业务人员完成配置—验证—发布—查询，AI 使用同一套确定性的语义接口。生产就绪还要求真实身份、授权撤销、故障恢复和部署演练；不以 demo 测试代替。

## 判断

现有领域包、独立接入绑定、Python 模块化单体与不可变 release 方向合理，不需要重写项目或增加一套图数据库执行层。当前不足主要在公共执行契约、权限和可靠性；页面原型已经较完整，但不能弥补这些缺口。

截图混合了“功能未实现”“合成子场景通过”“未重新验证”三种状态。A45 使用进程内 DraftStore 只能证明本地协议复用，不能关闭外部 Action 的幂等/恢复。A50 还含根对象维度解析、路径基数与 Action 前提，修好属性 Mapping 不等于整个 A50 通过。A60 的代码关键词检查不能证明 Compiler 已完全脱离物理字段。

## 本轮已修复

- `/v0.1/describe`、`/v0.1/search`：只投影业务定义，遵循当前角色权限与租户激活版本，不暴露 Mapping、连接或授权配置。按 ID/标签/描述确定性匹配；结果有口径、粒度、单位，多候选要求选择，数量与输入长度有界。中文业务术语放领域标签，核心不写行业同义词。不是 LLM 搜索，也不是 MCP transport。
- `tax.Taxpayer.pg`：补齐真实合成对象表的 name/jurisdiction Mapping，关闭 G4 的这一条复现。
- 公共 Query/Claim 与语义发现接受现有 Studio 会话；POST 继续要求 Origin/CSRF，显式错误 Bearer 不回退会话，退出和 viewer 限制仍生效。Action 认证路径暂未统一。
- Metric observation 回传定义中的 unit/valueType，避免业务和 AI 拿到无单位金额。

本轮通过不关闭 A40/A41/A51 的历史版本、细粒度发现权限和完整 MCP 联合要求。

### 执行顺序与责任

1. 主 agent 先集中完成 M1，不让 UI 或测试 agent 临时设计另一套身份、表达式或物理转换；交出可执行契约后再完成 Rule 编辑。
2. 统一认证授权后，完成 Action、版本与证据可靠性；真实 MCP 复用这些服务，不能再独立维护规则和权限。
3. 最后进行 UI、跨领域、发行物的一次联合验收。G4/G5 现有产物作为验收输入，不把其 handoff 自动视为最终通过。

使用原有架构与声明范围，不新增聊天产品、任意 SQL 查询器、通用 ETL 或“支持所有协议”的承诺。真实 remote-dev 只读样本继续作为本地业务参考；自动化测试只用隔离合成库。审计因子单位/缩放与业务最终版仍需确认，不据此生成正式对账政策。

## 上一轮验收证据（当前结果见 AI 分析与主实现 handoff）

本轮最终隔离 PostgreSQL 全量回归为 **144 passed、1 failed、1 skipped**；唯一失败是 G4 的 JWT 缺口标记，跳过是真实 MCP 未就绪。现有 15 项 Playwright 浏览器用例全部通过，覆盖 G1–G3 已交付路径，但不包含尚缺的完整负载与对象/字段权限证明。格式、类型与前端类型检查通过。详细记录在 `.agents/maturity-closure/handoff.md`。

G4 的 JWT 用例目前直接 `pytest.fail`，它是缺口标记，不是有效的签名验证测试；实现真实认证时应替换成实际构造有效/伪造/过期 token 的正反例，不能直接删除失败或改 skip。生产认证未实现这一事实仍成立。

未通过项目不会因现有测试数量多而关闭。T09A/B/C 统一按“切片已验、联合未关闭”记录；T08A 保持进行中。发布授权只约束实际发布，不应阻止构建与准备；没有签名 SBOM 也不能凭空变成契约外的前置条件。T08B 独立要求实际试点授权、负载/保留/恢复要求及真实环境证据。
