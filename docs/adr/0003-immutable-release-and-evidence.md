# 0003 — 请求固定发布版本，证据显式声明可重放等级

状态：accepted。

Git 中的声明产生内容寻址、精确依赖的 Semantic Release，Registry 保存发布物和受控部署索引；每次请求固定 release digest、环境绑定及执行 profile，使用当前有效授权。回滚改变后续请求的部署指针，不改变历史发布物，不恢复旧访问权；已批准操作仍须验证当前条件与原绑定兼容。

Evidence 默认保留受控来源引用、版本及哈希，也允许配置最小加密输入快照；明确区分只能追踪、能核对来源历史、能用保留输入重算。仅凭主键和哈希不宣称可以历史重放。这个选择避免复制完整事实仓库，但需要显式的数据保留策略。

[ADR-0008](0008-studio-and-metadata.md) 扩展可信编辑来源为受审核 Git commit 或 Studio 草稿 revision；两者仍产生同一不可变 release 并遵守当前授权。
