# 0017 — 集合分析是可组合计划，比较不是请求枚举

状态：accepted，2026-09-22。替代 [ADR-0011](0011-semantic-query-planner.md) 中把占比、相对均值、严格同行比较和上一期冻结为 `SemanticQuery.comparison` 枚举的决定。不开放调用方 SQL，不改变缺失、精度、授权和证据不变量。

## 决策

1. **请求表达组合，不点名业务比较。** `SemanticQuery.formula` 是 `VALUE`、`RATIO` 或 `DIFFERENCE`。每个操作数是一次聚合：指标、聚合算子、以及 `QUERY` / `SUBJECT` / `PEERS` 范围。`SUBJECT` 和 `PEERS` 只作用于该操作数；总体筛选留在请求的 `filters` 上，主体条件不能缩小分母。
2. **上一期是已观测范围的前一个值。** `previousObserved` 把唯一被等值约束的范围属性改绑到已授权观测序列中的前一个值，结果就是该期的聚合。它不要求 `time.year` 或 `time.sequence` 角色，也不按「月环比」这类短语提前拒绝。短语能否执行，取决于本体里是否有可排序的范围，而不是词表。
3. **两个指标的差或比走同一条路径。** 公式的左右操作数可以是不同的指标。执行器分别聚合再做标量运算，证据记下公式和实际使用的映射。
4. **不能执行的集合关系在编译期拒绝。** `Link.collection: true` 表示这条关系要参与集合分析。基数不是 ONE，或身份不是单字段，编译失败，诊断写明关系 ID，以及缺少展开策略或身份不受支持。未声明 `collection` 的一对多关系仍可用于点查。已编译接受的 ONE 单键等值连接必须能执行，并与独立 SQL 一致。
5. **普通测量词条只写身份、属性和叫法。** 单位、粒度和可加性从测量槽与映射继承。四位年份绑定到唯一的整数范围属性，不要求时间角色。
6. **语言只产出本体候选。** 分组按属性标签、别名和对象标签解析。认不出的分组进入澄清。语言适配器不写行业名词表，也不在看到本体之前把某种问法判成不支持。

## 影响

- 删除 `ComparisonOp` 以及 `SHARE_OF_TOTAL`、`RELATIVE_TO_MEAN`、`STRICT_PEER`、`PERIOD_OVER_PERIOD` 请求字段。
- Chat 与 HTTP 仍只有 `prepare` / `execute`。窗口、递归、无界一对多和调用方 SQL 继续拒绝。
- [语义契约](../spec/semantic-contract-v0.1.md) 的集合分析小节按本决定更新。

## 不做什么

- 不实现一对多展开策略。声明了集合用途又没有可执行形状时，发布失败。
- 当前公式操作数限于同一 PostgreSQL 来源及事实表；跨源 Link 的普通集合路径保持既有能力，公式与跨源 bind-join 的组合明确拒绝，未计为本次验收。
- 不把临时公式自动写成正式指标或规则。
- 不保证自然语言理解的完备性。歧义仍用选择题，不猜测分母。
