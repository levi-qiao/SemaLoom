# 0005 — Python 主体，拥有业务语义，复用成熟基础设施

状态：accepted。

采用 Python 模块化单体。核心拥有语义 IR、规划、规则语义及受控操作；小型关系计划通过 SQLAlchemy Core 构造参数化 SQL，adapter 以行为契约验证。

规则采用无循环、无任意函数调用的类型化表达式树，以 Decimal 执行有限算术与比较。这需要维护受限解释器，但能明确掌握金额精度、缺失值与资源预算。

复用连接、协议、校验和持久化基础设施；第三方对象留在实现内。新增依赖或维护 fork 需要具体缺口、测试及维护责任。能力分工见 [architecture](../architecture.md)。
