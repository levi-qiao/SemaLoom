# 0001 — 语义运行时与领域包分离

状态：accepted。

SemaLoom 的核心是确定性的业务查询、判断与操作，不以 RDF Store 或某个行业模型为中心。采用 Python 模块化单体，业务事实保留在来源系统，行业定义放在领域包；首条链路通过 SQLAlchemy Core 直接访问 PostgreSQL。这样可先验证语义契约，避免同时承担图推理、联邦优化及分布式服务的复杂度。

新增 adapter 由实际接入需求和兼容性验证驱动。首版范围为精确粒度查询、有限声明式关系、确定性规则与受控草稿操作。

领域定义与物理接入声明的职责进一步由 [ADR-0006](0006-independent-integration-layer.md) 分离；本决策的单体部署与事实留源原则保持有效。
