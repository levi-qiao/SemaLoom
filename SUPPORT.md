# Support

SemaLoom is pre-alpha software maintained on a best-effort basis.

- Ask usage and design questions in [GitHub Discussions](https://github.com/levi-qiao/SemaLoom/discussions).
- Report reproducible defects with the bug report form.
- Propose scoped changes with the feature request form.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities or sensitive reports.

Do not include credentials, real business records, or private schema details in public posts. There
is currently no paid support channel or guaranteed response time.
