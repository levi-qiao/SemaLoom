# 合成采购示例

该领域包只使用虚构标识和金额，展示无需修改通用核心即可声明：

- 订单、组织、供应商与年度采购合同四类对象；
- 同库组织关系与跨库供应商关系；
- 状态、区域、合同类别等取值字典驱动的筛选和补充选择；
- CNY、EA 与不可加比率三类测量语义；
- 合同可用余额、合同使用率两个派生指标，以及合同金额上限的三值判断；
- PostgreSQL 读映射、OpenAPI 风险属性和受控采购草稿 Action。

`local-dev` 会载入 4 个订单、2 个组织、3 个供应商和两个会计期间的 6 份合同。`tenant-b` 的隔离行只用于验证租户边界。这里故意使用字符串账期，证明核心不依赖“年份必须是整数”。可重复尝试的问题包括：

1. 选择会计期间 `2025-01` 后查询合同总额合计 → `6500 CNY`。
2. 在 `2025-01` 按合同类别查看合同总额 → 货物、服务、物流三类结果。
3. 查询 `2025-01` 的合同已承诺金额 → 明确提示 1 份缺失；只有用户允许排除缺失后才计算。
4. `CT-2024-001 的合同是否超额` → 通过已发布规则产生确定性判断。
5. `按供应商名称汇总采购金额` → 通过声明的跨库 `ONE` Link 做有界 bind-join。

这些数据仅用于开源演示，不代表真实采购台账、审批意见或供应商评价。
