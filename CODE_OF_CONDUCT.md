# Code of Conduct

We want SemaLoom to be a respectful, practical, and welcoming project.

## Our standards

Examples of behavior that helps the project include:

- Giving and accepting specific, constructive feedback.
- Respecting different backgrounds, experience levels, and viewpoints.
- Focusing discussion on observable behavior and technical tradeoffs.
- Protecting confidential information and reporting security issues privately.

Harassment, personal attacks, discrimination, threats, deliberate disruption, and publishing
someone else's private information are not acceptable.

## Enforcement

Project maintainers may edit or remove contributions and may temporarily or permanently restrict
participation when behavior violates these standards. Maintainers will explain moderation decisions
when doing so would not expose private or sensitive information.

Report community concerns through a private contact method listed on the
[maintainer's GitHub profile](https://github.com/levi-qiao). Report vulnerabilities through the
private channel described in [SECURITY.md](SECURITY.md).
